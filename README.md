## Как пользоваться

- Откройте неделю и выберите номер задачи в её начале. Вверху и внизу каждой страницы есть переходы между неделями и ссылка на общий указатель.
- В [указателе](TASKS.md) собраны все номера и названия. Поиск браузера **Ctrl+F** (на macOS **⌘F**) поможет быстро найти нужный номер.
- Формулы читаются прямо на GitHub во вкладке **Preview**; установка программ не нужна. На узком экране длинную формулу можно прокрутить горизонтально. Рисунок можно открыть отдельно и увеличить.
- Для чтения без интернета скачайте архив и сохраните папки `weeks` и `assets` вместе. В локальном просмотрщике Markdown должна быть включена поддержка математических формул и блоков `math`.

Задачи с индексами **0** и **Т** даны по материалам семинаров. Во второй неделе задачи об излучении имеют номера **11.26, 11.38, 11.50, 11.44, 11.76** — по актуальному разделу 11 задачника. Существенные опечатки в условиях и расхождения с печатными ответами поясняются в самих решениях.

**Нашли ошибку?** [Сообщите номер задачи и спорный шаг](https://github.com/NeTotDEDD/FIZOS_Kvanty/issues/new?template=correction.yml) — так исправление поможет всем, кто готовится по этим материалам.
